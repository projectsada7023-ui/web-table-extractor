# Web Table Extractor Browser Extension

This is the Manifest V3 browser extension for the Web Table Extractor project.

## What it does

1. Open a webpage containing an HTML table.
2. Click the Web Table Extractor extension.
3. The extension detects HTML tables on the current page.
4. Select a table to preview it.
5. Export the selected table as CSV.

## Install in Chrome

1. Open `chrome://extensions`.
2. Turn on **Developer mode**.
3. Click **Load unpacked**.
4. Select this repository's `extension` folder.
5. Open a webpage containing a table.
6. Click the extension icon.

This MVP exports CSV. Excel/JSON and more advanced table detection can be added in later iterations.
